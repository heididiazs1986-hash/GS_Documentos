# Paleta oficial GS

Esta es la identidad visual base para las aplicaciones de Gestión Social (GS).

## Colores
- Primary — APPLUS Orange: `#FF6600`
- Secondary — Support Gray: `#C1C7CE`
- Tertiary — Accent Blue: `#79D1FF`
- Neutral — Light Neutral: `#FEFEFF`

## Tipografía
- Titulares: Open Sans, semibold/bold.
- Cuerpo y etiquetas: Manrope, regular/medium/semibold.
- Fallback: Segoe UI / Arial / sans-serif.

## Uso
- Primary: botones principales, llamadas a la acción, elementos activos y acentos de marca.
- Secondary: bordes, superficies de apoyo y controles secundarios.
- Tertiary: información, resaltados suaves y estados informativos.
- Neutral: fondos y superficies limpias.

GS Firmas adopta esta paleta como referencia oficial. Los colores de estado (éxito/error) son funcionales y no sustituyen la paleta de marca.
